# 肿研通 · Oncology Trial Hub

通过用户浏览器访问药物临床试验登记与信息公示平台，按关键词遍历、采集公开详情、按 CTR 去重，再导出项目与入排标准。仓库为独立工具，不代表 CDE 官方。

## 交付成果（2026-09-28）

- 已保存 3,259 个唯一 CTR，重复 CTR 为 0。
- 其中 2,823 条详情为进行中且招募中；剔除 5 条明确关键词误召回后，交付 2,818 个唯一 CTR。公开清单位于仓库根目录，剔除理由另存。
- 28 组同标题不同 CTR 均保留；仅以 CTR 判重。
- 六关键词已遍历。瘤为 1,572/1,573，癌为 1,286/1,287；另外四关键词数量一致。两处各 1 条差异接受保留，coverage 原值不改为完成。
- 不能把关键词覆盖等同于医学复核后的全库完整性。保留支持治疗、健康受试者、良性或中间性肿瘤等相关研究，不等同于全部为恶性肿瘤患者治疗试验。
- 完整 Excel、CSV、JSON 已交付并备份外接硬盘，文件哈希一致。公开成果提供项目索引、适应症、状态、采集时间与官网入口，不包含联系人姓名、电话、邮箱或原始浏览器导出。

## 工作流程

1. 在正常可访问官网的 Chrome 会话中加载 browser-extension 本地扩展。
2. 以瘤、癌、白血病、骨髓增生异常、骨髓增殖、浆细胞分别检索适应症。
3. 串行读取列表与详情，限速、保存断点；遇网站验证由用户正常处理。
4. 导出浏览器 JSON，保留原始采集时间和各关键词覆盖信息。
5. 使用 `python crawler.py --import-browser 文件.json` 生成本地表格。默认仅保留进行中且招募中候选；不会自动完成医学范围复核。
6. 以 CTR 去重；不同 CTR 即使标题相同也保留。
7. 最终交付前复核肿瘤范围，核对文件记录数与备份哈希。本次已核对导出记录数与备份哈希；分类为文本辅助范围筛选，不是逐项目医学判定。

## 本地完整输出字段

CTR、项目名、关键入排原文摘录、完整标准、申请人联系方式、主要研究者联系方式、适应症、状态、来源和采集时间。申请人联系方式优先展示。关键摘录是规则选取，不代替完整入排标准。
